# Jeux

## Dossier Val d'Aurelle

Jeu de rôle d'audit légal, dans le navigateur : vous êtes commissaire aux comptes et vous auditez les comptes 2025 de Val d'Aurelle Habitat, une entreprise sociale pour l'habitat fictive. Le dossier comptable complet (grand livre, FEC, états financiers, annexe, pièces) est généré par le moteur du jeu.

Le projet est dans [`dossier-val-aurelle/`](dossier-val-aurelle/) :

```bash
cd dossier-val-aurelle
npm install
npm run dev     # jeu en développement
npm test        # tests
npm run build   # site statique (dist/) ; « npm run build:single » : fichier HTML unique hors ligne
```

Cahier des charges, plans et points à vérifier : [`dossier-val-aurelle/docs/`](dossier-val-aurelle/docs/).
