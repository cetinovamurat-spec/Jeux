# Dépôt Jeux

Un seul projet : **`dossier-val-aurelle/`** — « Dossier Val d'Aurelle », jeu de rôle d'audit légal d'un organisme de logement social (Vite, React, TypeScript, 100 % navigateur), projet autonome avec son propre `package.json`. Toutes les instructions de travail sont dans [`dossier-val-aurelle/CLAUDE.md`](dossier-val-aurelle/CLAUDE.md).

Les commandes (`npm install`, `npm test`, `npm run build`…) se lancent depuis `dossier-val-aurelle/`.

« Les Olympiades du Cabinet » (party game Node / Socket.io déployé sur Render), qui occupait auparavant la racine, a été retiré du dépôt le 16/10/2026 ; il reste disponible dans l'historique Git (commits antérieurs à son retrait).
